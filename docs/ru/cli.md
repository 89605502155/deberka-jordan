# Командная строка

Программа называется `deberka-jordan`. Подкоманды: `plan`, `net` и `deadband`.

    deberka-jordan --version

## `plan`

Строит план Жордана одного цикла и проверяет порядок операций. Вход — CSV с колонками
`consumer,current,target` (МиБ).

    deberka-jordan plan state.csv --pool 100 --deadband 64

Печатает JSON с полями `donors`, `recipients`, `skipped`, `take`, `give`, `volume`,
`pool_before`, `pool_peak`, `pool_after`, `rationed`, `min_pool_two_phase`,
`min_pool_recipients_first` и списками фаз `phase1`, `phase2`.

| Параметр | Смысл | По умолчанию |
|---|---|---|
| `--pool` | свободный пул до цикла, МиБ | обязателен |
| `--deadband` | изменения меньше этой величины пропускаются, МиБ | 0 |
| `--factor` | единица `volume`: 1 = перенесённые между потребителями байты, 2 = балонные операции | 1 |

## `net`

Выигрыш взаимозачёта по циклам для журнала предложений с колонками
`cycle,source,recipient,amount` (допустимы синонимы `donor` и `amount_mib`).

    deberka-jordan net proposals.csv --out netting.csv

Печатает сводный JSON: число циклов, объёмы поочерёдного и жорданова исполнения, общий
выигрыш и медианное отношение. `--out` записывает строку на цикл. `--factor` (по умолчанию 1, байты)
задаёт единицу обоих объёмов; `--factor 2` даёт балонные операции. Выигрыш от единицы не
зависит (см. теорию, раздел 2).

## `deadband`

Проигрывает контроллер резерва с несколькими порогами на трассе потребности. Трасса —
широкий CSV с колонкой `t_s` (равномерная сетка) и колонкой на каждого потребителя.

    deberka-jordan deadband trace.csv --h 0,64,128 --reserve 256 --theta 64 --out sweep.csv

| Параметр | Смысл | По умолчанию |
|---|---|---|
| `--h` | пороги через запятую, МиБ | `0,8,16,32,64,96,128,192,256` |
| `--reserve` | резерв над потребностью, МиБ | 256 |
| `--interval` | интервал мониторинга, с | шаг трассы |
| `--theta` | порог дефицита, МиБ | 64 |
| `--window` | окно индекса колебаний, с | 60 |
| `--kappa-target` | целевая медиана `κ` для выбора | 0,5 |
| `--out` | CSV со строкой на порог | нет |

В конце таблицы печатается выбранный порог: наименьший, у которого медиана индекса не
выше цели. Код возврата 0 при успехе.
